🍳 TablePlan: Setup Guide

Recipes, auto meal plans, a smart pantry and grocery lists, self-hosted on GrandHub. Mealie is included, so you don't need to install it separately. TablePlan's setup wizard creates your recipe account for you.

How it fits together

🏠 TablePlan · port 9930The app you use every day: plans, pantry, lists, email and print. The setup wizard lives here.
🍲 Mealie · port 9925The recipe engine, installed automatically. It stores recipes, does AI imports and scales servings. You rarely need to open it.
🐙 GitHubHolds the code. Every push builds a new version and publishes it to your private ZimaOS app store.
git push ──► GitHub Actions ─┬─► container image ghcr.io/thomasjvalenzuela/tableplan └─► ZimaOS app store thomasjvalenzuela.github.io/tableplan │ ZimaOS App Store ◄───┘ shows "Update" whenever you push

You do steps 1–2 once, as the developer. Steps 3–5 are the install. They're also what anyone else you share TablePlan with would do.

1 Publish the code to GitHub

Unzip tableplan-repo.zip from the chat. It's already a git repository with one commit. Then create the GitHub repo and push it, using either way below.

With the GitHub CLI (one command)

in the unzipped tableplan folder
cd ~/Downloads/tableplan
gh repo create thomasjvalenzuela/tableplan --public --source=. --push

Or with the website

  1. Go to github.com/new. Name it tableplan, choose Public, and don't add a README.
  2. Then run:
in the unzipped tableplan folder
cd ~/Downloads/tableplan
git remote add origin https://github.com/thomasjvalenzuela/tableplan.git
git push -u origin main
Why public?

ZimaOS downloads the app and its store listing without logging in to GitHub, so the repo, the Pages site and the container image all need to be public. Your recipes and data never leave GrandHub. If you want a private repo later, it's possible, but ZimaOS would need registry credentials.

2 Turn on Pages & make the image public

  1. Open the repo → Actions. The Release workflow runs automatically on your push. Wait for the green check, about 5–8 minutes the first time.
  2. Settings → Pages: under Build and deployment, set Source to Deploy from a branch, and Branch to gh-pages / root. Save.
  3. Your GitHub profile → Packages → tableplan → Package settings. Scroll to Danger Zone → Change visibility → Public.
  4. Check that it worked by opening thomasjvalenzuela.github.io/tableplan/version.json. It should show the version number. Pages can take a minute to go live.

3 Install on ZimaOS

Pick one of these. Option A gives you update prompts in ZimaOS.

Option A: ZimaOS App Store (recommended)

  1. Open ZimaOS → App Store → the ⋯ / settings menu → Add source (on some versions it's called App Store sources or Third-party store).
  2. Paste the address below and save:
store source
https://thomasjvalenzuela.github.io/tableplan
  1. Search for TablePlan and tap Install. Mealie downloads with it, which takes a few minutes the first time.
  2. When the TablePlan tile appears on your ZimaOS dashboard, open it.
Your data folder

The store installs to /DATA/AppData/tableplan, the ZimaOS default. To keep it on your big disk, open TablePlan's install settings before tapping Install and change both volume paths to /media/DATA/AppData/tableplan/…. Never use the old MEDIA disk.

Option B: one SSH command

on your computer
ssh thomasadmin@192.168.0.158
then on GrandHub
curl -fsSL https://thomasjvalenzuela.github.io/tableplan/install.sh | sudo bash

The installer:

  • checks Docker and that ports 9930 and 9925 are free
  • installs to /media/DATA/AppData/tableplan
  • starts both containers
  • prints the address to open

Running it again later updates TablePlan. Your data is kept. You can also manage it with:

manage
sudo tableplan status      # is it running?
sudo tableplan update      # get the latest version
sudo tableplan logs        # see what it's doing
sudo tableplan backup      # zip up your data
sudo tableplan uninstall   # remove containers, keep data
Confirm the address

The installer prints GrandHub's current IP address. Use that one, since 192.168.0.158 can change.

4 Run the setup wizard

Open http://192.168.0.158:9930. The wizard starts automatically. You can skip any step and finish it later in Settings.

ScreenWhat to enterWhere to get it
HouseholdA name, and how many people you cook forEvery recipe you plan is scaled to this number.
Recipe libraryYour name, email and a password (8+ characters)This creates your Mealie login and replaces Mealie's default account. TablePlan makes its own secure token, so you never copy one by hand.
Import from screenshotsAn OpenAI API key. Leave the model as gpt-5-mini.platform.openai.com/api-keys → Create new secret key. Add about $5 of credit, which covers hundreds of imports. TablePlan tests the key before saving it.
EmailProvider, your address, and an app passwordGmail / Workspace: Google Account → Security → 2-Step Verification → App passwords. TablePlan sends a test email to confirm it works.
Lock itOptional household passwordLeave it blank if only your home Wi-Fi can reach TablePlan.
Change anything later

Go to Settings → Setup to change the household size, reconnect Mealie, replace the OpenAI key, change email settings, or add or remove the password. Run setup wizard again is at the bottom of Settings.

How updates reach you

You doWhat happens automatically
Edit the code and run git pushGitHub Actions builds version 0.2.N for both Intel and ARM servers. It publishes the image and the updated store listing, using the first line of your commit message as the release note.
NothingZimaOS: the App Store sees the new version and shows Update on TablePlan.
TablePlan: a blue "Update available" banner appears on Home and in Settings, telling you how to update.
Bigger releaseChange VERSION (for example 0.2 → 0.3) and push.
Upgrade MealieChange the Mealie image tag in zimaos-store/Apps/TablePlan/docker-compose.yml and install/install.sh, then push.
SSH installs

If you used Option B, updates arrive as the in-app banner. Run sudo tableplan update to install them.

Everyday use

I want to…Do this
Save a recipeHome → + → paste a link, or switch to Screenshot / Photo and pick images
Plan the week or monthMeals → Auto-plan → Generate → swap 🔀 or remove ✕ any pick → Save
Make the grocery listMeals → Add to list. Ingredients are scaled for your household, merged, and anything already in the pantry is skipped.
ShopList tab → tap each item as it goes in the cart. Food moves into the pantry with a use-by date.
Log what we usedPantry → item → ¼ / ½ / ¾ / All. The first use switches the item to its after-opening date (heavy cream → 7 days).
Share or printThe Share button on Meals, List or Pantry: email, print, CSV, or calendar (.ics)

Troubleshooting

SymptomFix
The Release workflow fails at "Log in to GHCR" or "push"Repo Settings → Actions → General → Workflow permissions → Read and write, then re-run the workflow.
ZimaOS can't add the store, or shows no appsCheck that Pages is on (step 2) and that …github.io/tableplan/index.json opens. New Pages sites can take up to 10 minutes.
Install fails with "pull access denied"The image is still private. Do step 2.3 (make the package public).
Wizard says "Can't reach Mealie yet"Mealie needs about a minute on first start. Tap Check again.
Wizard says "This Mealie already has an account"Someone already set up this Mealie. Switch to Sign in with that login.
OpenAI test failedThe key is wrong, or the account has no credit. Billing is at platform.openai.com.
Email test failedFor Gmail, use an App Password, not your normal password. It needs 2-Step Verification turned on.
Forgot the TablePlan passwordOn GrandHub, run sudo docker exec tableplan python -c "import sqlite3;c=sqlite3.connect('/data/tableplan.db');c.execute("DELETE FROM settings WHERE key='cfg.app_password_hash'");c.commit()", then sudo docker restart tableplan.
