🍳 Install TablePlan

TablePlan is a self-hosted household kitchen app. It handles recipes from links and screenshots, auto-generated meal plans, a pantry that tracks real use-by dates, and grocery lists you can email or print. It runs on your own server, and Mealie is bundled as the recipe engine.

Tick each step as you finish it. Your progress is saved in this browser.

What you need

🖥️ A server with DockerZimaOS, CasaOS, Ubuntu/Debian, a NAS, or a Raspberry Pi 4/5. Both Intel/AMD (amd64) and ARM (arm64) work.
💾 1.5 GB RAM, 2 GB diskMealie uses most of it. Your recipes and photos take more space over time.
🔌 Ports 9930 and 9925TablePlan on 9930 and Mealie on 9925. You can change both.

Optional:

  • An OpenAI API key to import recipes from screenshots, photos and video links. It costs a few cents per recipe.
  • An email account that allows SMTP, such as Gmail with an App Password, to email yourself lists and plans.

1 Install

First: do you already use Mealie?

No, I don't have Mealie (most people)Yes, I already run Mealie
What gets installedTablePlan plus a fresh MealieOnly TablePlan, connected to your Mealie
Install withAny method belowThe one-command installer with MEALIE_URL=…, or docker-compose.existing-mealie.yml. Not the ZimaOS App Store version, which adds a second Mealie.
In the wizardCreate accountSign in with your Mealie login (an admin, for AI setup)

Everything else is the same. If you already have Mealie, use your server's network IP in MEALIE_URL (for example http://192.168.1.50:9925), never localhost:

existing Mealie, one command
curl -fsSL https://thomasjvalenzuela.github.io/tableplan/install.sh | sudo MEALIE_URL=http://192.168.1.50:9925 bash

Otherwise, choose the method that matches your server.

ZimaOS (App Store, recommended)

  1. Open App Store → Community store → Add, and paste:
community store URL
https://thomasjvalenzuela.github.io/tableplan/store.json
  1. Switch to the TablePlan store and click TablePlan → Install. Mealie installs with it.
  2. Optional: before installing, change the volume paths if you keep app data on a different disk. The default is /DATA/AppData/tableplan.

ZimaOS shows an Update button whenever a new version is released.

Any Linux server with Docker (one command)

This covers CasaOS, Ubuntu/Debian and similar. SSH into the server and run:

on the server
curl -fsSL https://thomasjvalenzuela.github.io/tableplan/install.sh | sudo bash

The installer:

  • checks Docker and that ports 9930 and 9925 are free
  • picks an install folder: /media/DATA/AppData/tableplan, /DATA/AppData/tableplan or /opt/tableplan, whichever exists
  • starts both containers
  • prints the address to open

You can choose different ports or a different folder:

custom ports / folder
curl -fsSL https://thomasjvalenzuela.github.io/tableplan/install.sh | sudo TABLEPLAN_PORT=8930 MEALIE_PORT=8925 TABLEPLAN_DIR=/srv/tableplan bash
Want to read it first?

It's a good habit to read a script before piping it to sudo. Download it and read it first:
curl -fsSLO https://thomasjvalenzuela.github.io/tableplan/install.sh && less install.sh && sudo bash install.sh

Docker Compose / Portainer / Dockge / Unraid

terminal
mkdir tableplan && cd tableplan
curl -fsSLO https://thomasjvalenzuela.github.io/tableplan/docker-compose.yml
nano docker-compose.yml        # optional: set TZ, change ports
docker compose up -d

In Portainer, go to Stacks → Add stack and paste the contents of docker-compose.yml.

Already running Mealie v3? Use docker-compose.existing-mealie.yml instead, set MEALIE_URL to your Mealie address, and choose Sign in in the wizard.

First start takes a few minutes

Mealie downloads about 500 MB and sets up its database on first start. Wait for both containers to show Running or healthy.

Backup & uninstall

Everything lives in two folders: data/ for TablePlan (pantry, settings and shelf-life rules) and mealie/ for recipes, photos, plans and lists. Back up both.

installer users
sudo tableplan backup      # writes tableplan-backup-DATE.tgz next to the install folder
sudo tableplan uninstall   # removes containers, keeps your data
compose users
docker compose stop && tar czf tableplan-backup.tgz data mealie && docker compose start
docker compose down        # uninstall; delete the folder to remove data too

Mealie also has built-in backups under Settings → Backups.

Using it away from home

  • Recommended: a private network such as Tailscale, so your phone reaches the server as if you were at home. Nothing is exposed to the internet.
  • Public domain: put TablePlan and Mealie behind a reverse proxy with HTTPS, such as Caddy, Nginx Proxy Manager or Traefik. Set a household password in the wizard, and set MEALIE_PUBLIC_URL so recipe links use your domain.
  • Don't port-forward 9930 or 9925 directly on your router.

FAQ

Does my data leave my server?
No, with two exceptions you turn on yourself: screenshot imports go to OpenAI, and emails go through your mail provider. The only other outside requests are one download of the public USDA FoodKeeper shelf-life database and a version check against GitHub Pages.

Where do the use-by dates come from?
From the USDA FoodKeeper database, always using the low end of its ranges to stay safe. When you open or freeze something, it switches to the matching "after opening" or "freezer" time. A date you type from the package always wins. You can edit any rule in Settings.

Can I use my existing Mealie?
Yes. Use docker-compose.existing-mealie.yml and sign in during the wizard. Your recipes, plans and lists stay in Mealie.

What does it cost?
TablePlan and Mealie are free and open source. AI imports use your own OpenAI account, at a few cents per recipe.
